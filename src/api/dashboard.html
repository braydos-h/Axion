        Passive monitoring vs. enforcement

        What this demo shows

        Axion evaluates every rule and records the resulting ALLOW, LOG, MONITOR, DROP or REJECT verdict. The event stream and flow table show the real classifier output and the real matched rule.

        What is intentionally different

        This server runs without capture privileges and without NFQUEUE. Drop/REJECT verdicts stop at the policy layer: no packet is discarded. Only an inline NFQUEUE deployment can enforce them on a host.

        No decryption claims

        TLS application data, TLS-wrapped VLESS/Trojan, REALITY and VMess remain encrypted. Axion classifies only observable metadata and plaintext headers. The VLESS/Trojan demos use fixtures whose headers are visible.

        Axion performs passive inspection unless an NFQUEUE backend is active. Encrypted payloads are classified only from observable metadata.

        Demo replay uses isolated monitor-only engines with embedded fixtures. Management API binds to localhost by default.
